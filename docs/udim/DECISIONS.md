## Design items (status: open / decided + decision)
1. Tile source: tile of each triangle from UV centre at import; split shared verts at borders; clamp straddling triangles + console warning. - DECIDED: accepted as recommended (clamp with warning, don't refuse import).
2. GPU side: mesh UVs become atlas coords (tile-local UVs + tile ids kept in runtime, file stores tile-local); fragment tile = floor(uv*stride); drops per-object atlas uniform and per-object bake remap. - DECIDED: option A accepted (best perf, moderate code impact, no pipeline changes). Rejected: per-vertex tile-id attribute (touches every pipeline), per-tile textures.
3. Texture storage: one atlas per project keyed by saved sorted tile list; resolution is per tile; show memory estimate; tile-list change copies tiles and resets undo. - DECIDED: single atlas with a PIXEL BUDGET instead of fixed 64 cap (grid grows as needed, per-tile res auto-clamped so atlas <= 16384, UI shows actual per-tile res and memory; verify 8x8 is just a constant). Realistic target ~1-64 tiles; beyond that show 'too large for single atlas' (future: streaming/sparse tiles would replace storage layer only). User confirmed target range fits.
4. Layer data: all_objects + object ids, all_tiles + tile ids; permanent never-reused object ids; join adds survivor to sets. - DECIDED: accepted as written. Coverage=(obj in set or all_objects) AND (tile in set or all_tiles); persistent never-reused object ids; tile ids; id ranges in shader; a duplicate gets a new id and is NOT added to explicit selections.
5. Rendering: shader id/tile ranges (no 32/64 limit), paint merges covered objects + tile discard, sculpt per-vertex coverage texture, flatten/path trace/export use UV footprint mask; overlapping UVs in one tile indistinguishable. - DECIDED: accepted. Overlap limit documented, not solved. No warning icon: the Objects combo tooltip gets an extra sentence ONLY when the limit applies (layer object-restricted AND a covered object overlaps an uncovered object in UV on the same tile; cheap UV bbox pass then low-res raster, cached per set+mesh version). Text when it applies: 'X shares UV space with Y on tile T. In exports and path tracing this layer also applies to Y.' Base tooltip: 'Limit this layer to the selected objects.' Tile combo: 'Limit this layer to the selected UDIM tiles.' No-objects indicator tooltip: 'This layer's objects were deleted, so it covers nothing. Select objects or choose All to use it again.' Status hint when painting: 'Layer covers no objects'.
6. Save format v24 and migration of old files (masks, atlas groups, name-based UDIM projects, resolution old/stride). - DECIDED: fork format version string "99" (loader compares version by exact string; legacy table is 0..22 so "99" files cleanly fail in upstream, and upstream v23 files need a new from_version_23 converter in the fork). NO real migration: minimal v23 converter only (all layers all_objects/all_tiles, object ids 1..N, udim_tiles={1001}, old masks/atlas groups/name-based UDIM dropped). Fits 'don't care about historical files'. ISOLATION GOAL (user, CORRECTED): isolate ONLY the save/load format code (version "99" constant, v23 converter, encode/decode of the new layer/project/mesh fields) in one place so it's easy to handle in a fork situation. Everything else (UDIM logic, shaders, UI, export, bakes) should use whatever layout is best for the code, spread across files as needed; no FORK markers or touch-point list required for it. types.h struct fields are an unavoidable touch point for the format. Not tested cross-version loading.
7. Export: Visible/Selected/Per Object/Per Tile/new Per Object & Tile; `_1001` naming; drop Export > Atlases. - DECIDED: accepted as written (Per Tile default when >1 tile; `_1001` after channel; Export > Atlases removed; D3 on export groups still open).
8. Bakes: atlas file + per-tile `_1001` crops, re-crop after inpaint, "atlas UV" option on image nodes. - DECIDED: accepted as written, including the 'UV: Atlas' image node option; CPU bake warns above 8k atlas.
9. Import: "UDIM: Auto / On / Off" replaces "Split By: UDIM Tile". - DECIDED: accepted; UDIM tiles Auto/On/Off independent of Split By, default Auto; OBJ+FBX use shared helper; glTF/blend later; mesh export writes tile-local UDIM UVs.

## Decisions needed (from the agent)
D1. Do layers inside a group intersect with the group's coverage? - DECIDED: YES, intersection (effective coverage = own set AND every ancestor group's). No format change (runtime rule). Option when revisited: flatten uncovered areas as alpha 1.
